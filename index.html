Umbra and Reddit data

Umbra is a personal AI assistant, currently in private beta. This page explains exactly how it uses Reddit's Data API.

What Umbra does with Reddit

When a user asks a question that Reddit communities answer best, Umbra reads a few relevant public threads, summarizes the main points for that user, and links every point back to the original thread on reddit.com, so the user can read the full discussion and take part in it.

Example: "What standing desk under $500 do people recommend?" → Umbra searches r/StandingDesk and r/BuyItForLife, reads three threads, and answers with the desks people recommend and the complaints they raise, each with a link to its thread.

How it uses the API

  • Read-only. Search within a subreddit, top or new listings, and a thread with its comments. Nothing else.
  • Only when a user asks. No crawling, no bulk downloads, no background collection.
  • Low volume. About 200 requests a day at launch, under 10 a minute at peak, over OAuth with a descriptive User-Agent.
  • Public content only. No private, quarantined or NSFW-gated content.

What Umbra never does

  • Post, comment, vote or send messages.
  • Train AI models on Reddit data, or sell, license or share it.
  • Build profiles of Reddit users.
  • Get around Reddit's access controls. When Reddit blocks automated reading, Umbra tells the user plainly and uses other sources. It does not use mirrors, archives, proxies or scraping services, and it never solves bot checks itself.

Data handling

  • Umbra sends Reddit only the subreddit and search terms needed. No user identity, email or account data.
  • Content is fetched live when the user asks, so removed posts don't appear in new answers.
  • Reddit content is kept only inside that user's task, which the user can delete at any time.
  • Nothing from Reddit is passed to third parties.
